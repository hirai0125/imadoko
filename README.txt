今どこ君(GeoTIFF・SFC 現在地ビューア) オフライン版

【使い方の流れ】
1. このフォルダ一式を、HTTPSで公開できる場所に置きます(下の「公開方法」)。
2. Androidの Chrome で、電波のある場所でそのURLを一度開きます(部品がスマホに保存されます)。
3. Chromeのメニュー「︙」→「ホーム画面に追加」(または「アプリをインストール」)。
4. 以降はホーム画面のアイコンから、機内モードでも起動できます。
   位置情報は初回に「許可」してください。GPSは電波がなくても使えます。
5. GeoTIFF・SFCはスマホ内のファイルを「開く」で選びます(事前にスマホへ保存)。

【端末内・Box・Dropbox などから開く】
- 「📂 開く」または「☁ Box・Dropbox等から開く」を押すと、Androidのファイル選択画面が開きます。左上の「≡」から、端末内・Box・Dropbox・Googleドライブを選べます。虫眼鏡でファイル名の検索もできます(各アプリを入れてログインしておく)。
- Box/Dropboxなどのアプリ側から「共有」→「今どこ君」を選んで、直接送ることもできます(ホーム画面に追加したアプリのみ)。
- GeoTIFFとSXF(.sfc)・KML/KMZは中身で自動判別します。複数選択もでき、同時に読み込めます。
- 電波がない現場で使うファイルは、各アプリで「オフラインで利用可能」にしておいてください。

【部品について】
- 必要な部品(proj4・GeoTIFF・ZIP展開)は index.html の中にすべて埋め込んであります。別のlibフォルダは不要です。

【読み込みでエラーが出たとき】
- 画面下のバーに、ファイル名とエラーの内容・対処が出ます(タップで全文表示)。選んだファイルは、読み込む前にアプリ内へコピーします。
- 「ファイルを読めませんでした」と出たら、Box/Dropboxで「オフラインで利用可能」にするか、端末の「ダウンロード」フォルダへ保存してから選び直してください。

【背景地図(国土地理院タイル)】
- 画面上部「背景地図」で 淡色/標準/空中写真 を選びます(出典: 国土地理院。地図の読み込み後に表示)。
- 一度表示したタイルは端末に保存されます。電波のある所で「範囲をオフライン保存」を押すと、今の表示範囲(拡大側3段階まで)をまとめて保存でき、現場では機内モードでも表示されます。
- 「GeoTIFF濃度」スライダーで、GeoTIFFを薄くして背景を透かせます。

【画面の使い方】
- すべての操作は画面上部にまとめています(上から順に)。
  1段目: SXFの座標系・XY・単位(自動のときは判定結果を括弧内に表示。GeoTIFF/KML/現在地がなくても、図面内の都道府県名や前回の系から推定します。「?」付きは推定なので、違う場合は手動で選んでください)
  (SXF/KML読込後のみ) 図形の表示ON/OFF・色・表示範囲の移動
  2段目: 背景地図の選択・余白(外側の白/黒を透明に)・GeoTIFFの濃さ・オフライン保存(💾)
  3段目: ☁ Box・Dropbox等から開く・データのクリア
  4段目: 開く・現在地(2回目以降は現在地へ移動)・追従・全体表示・計測・▲(上の段を隠す/出す)
  距離計測中は、1点戻す・クリア・結果の行が4段目の下に出ます。
- 下のバーは状態表示です。タップすると全文を表示します。

【データのクリア】
- 上部の「データをクリア…」から、すべて/GeoTIFFのみ/SXFのみ/KMLのみ/距離計測のみ を消去できます(背景地図の保存データは消えません)。

【距離計測】
- 「距離計測」をONにして地図をタップすると点が追加され、区間ごとの距離と合計が表示されます(楕円体上の測地線距離)。
- 「1点戻す」「クリア」で修正できます。ドラッグで地図の移動、ピンチで拡大縮小は計測中もできます。

【現在地】
- 「現在地を取得」で青い十字マーカー(精度の円つき)を表示します。図面の範囲外でも、背景地図の上に表示されます。
- 「現在地へ」で現在地を画面中央に移動、「追従」で移動に合わせて画面を追従します。
- GPSは電波(モバイル通信)がなくても使えます。端末の位置情報はONにしてください。屋外で、初回は測位に少し時間がかかります。

【対応ファイル】
- GeoTIFF(.tif) / SXF(.sfc, Ver.2・Ver.3系) / KML・KMZ(.kml, .kmz) を「ファイルを開く」から選べます(複数同時に選択可)。
- KML/KMZ は線・面・点を表示します(Google Earth・QGIS等の出力、属性付きタグ、UTF-16、KMZ内の複数KMLにも対応。画像オーバーレイのみのKMLは表示できません)(色と太さはKMLの指定どおり)。表示範囲の移動は「表示範囲へ移動…」から。

【大容量GeoTIFF】
- 無圧縮の8bit TIFF(パレット/グレー/RGB)は、必要な行だけをファイルから直接読むので、100MB超でも少ないメモリで開けます。
- 巨大なGeoTIFFでも、全体は縮小して表示し、拡大すると表示範囲だけ高解像度で読み直します(メモリを抑えた読み込み)。
- 事前に PC で オーバービュー(縮小階層)を付けておくと、読み込みが速くなります。
  例: gdaladdo -r average 元.tif 2 4 8 16 32  (またはCOG形式で保存)
- オーバービューのない数GB級のTIFFは、初回の読み込みに時間がかかります。

【図面の枠の外に背景地図を出す】
- 画面上部の「余白透過」を押すと、画像の外周につながった白(または黒)の余白だけが透明になり、背景地図が見えます。
  枠の内側の白は残ります。押すたびに なし → 外側の白 → 外側の黒 と切り替わります。

【公開方法A: Netlify Drop(いちばん簡単・無料)】
 PCのブラウザで https://app.netlify.com/drop を開き、このフォルダをそのままドラッグ&ドロップ。
 表示されたURLをスマホで開きます。

【公開方法B: GitHub Pages(無料)】
 リポジトリを作り、このフォルダの中身をすべてアップロード。
 Settings → Pages → Branch: main / (root) を選んで保存。表示されたURLをスマホで開きます。

【更新するとき】
 index.html などを差し替えたら、sw.js の VERSION を v2, v3 … に変えてアップロード。
 スマホは電波のあるときに一度開くと新版に入れ替わります(2回開き直すと確実)。

【注意】
- ファイルを直接スマホで開く(file://)方式は、位置情報や保存機能が使えないことがあるため非推奨です。
- 読み込んだ地図は終了すると消えます。起動のたびにファイルを選び直してください。

【リンクだけのKMLについて】
 NetworkLink(外部リンク)だけのKMLは、リンク先を自動で取得します(http/https、Dropbox・Googleドライブの共有リンク対応)。
 相対リンクの場合は、リンク先のKMZ/KMLを同時に選択してください。取得できない場合は「ブラウザで開く」で保存し、📂開くで選びます。
 リンク先の名前が違っていても、同時に選んだKMZ/KMLが1つならそれを使います。KMZ(zip形式)は単体でも直接読み込めます。

【大きいKML/KMZ】
 数十MB以上のKML/KMZも、少しずつ読み込みます。画面下に進み具合(%)とバーを表示します(88MB・約360万点のKMLで確認)。
 読み込み中はアプリを閉じず、他のアプリを閉じてメモリを空けてください。

【SIM(SIMA)データ】
 .sim / .sima(座標データA01、区画・路線のB01)を「📂 開く」で読み込めます(Shift_JIS対応)。点・点名・区画/路線の線を表示します。
 座標系は図面内の都道府県名や背景地図から自動判定し、判定できない場合は上の「座標系」で選んでください。

【計測点の微調整】
 計測ONで置いた点は、点の近く(約1cm以内)から指でドラッグして動かせます。動かしている間は拡大表示(ルーペ)が出ます。
 選択中の点は黄色い輪で表示され、◀▲▼▶ボタンで少しずつ(画面2pxずつ)動かせます。

【SFCの円弧・文字の表示】
 円弧の回転方向(時計回り/反時計回り)を正しく扱い、文字は幅指定・基準点(左下/中央など)・回転に合わせて表示します。

【背景地図】
 初めて起動したときは、背景地図(国土地理院・淡色)が最初から選ばれています。「背景:なし」にしたい場合は、上の「背景」で切り替えてください(選んだ状態は次回も保たれます)。
 背景が出ないときは、電波・機内モード・データセーバー/VPN/広告ブロックを確認してください。

【ピン(コメント付き)】
 「📌 ピン」をONにして地図をタップするとピンが立ち、色(7色)とコメントを入力できます。ピンをタップすると編集・削除できます。
 「📋 一覧」でピンの一覧・移動・「KMLで保存」(Google Earth等で開けます)。ピンは端末に保存され、次回起動時も残ります。消去は「🗑 クリア…→ピンのみ」。

【ピンの位置を送る】
 ピンの編集画面の「📤 共有」「LINEで送る」で、コメントと地図リンク(Googleマップ)・緯度経度を送れます。受け取った人はリンクをタップすると地図で位置を開けます。
 「📋 一覧」の「全部を送る」「LINE」で全ピンをまとめて送り、「KML」でファイルとして送れます。

【v35 ピンに写真を付けられます】
・ピンの編集画面で「📷 撮影」(カメラ)または「🖼 写真を選ぶ」(アルバム)を押すと、そのピンに写真を追加できます(複数可)。
・写真は端末内に自動で縮小して保存します(長辺1600px)。サムネイルをタップで拡大、×で削除。
・地図上のピンには 📷枚数 が表示されます。
・「共有」では写真も一緒に送れます(LINEは共有メニューから選んでください)。
・ピン一覧の「KML出力」は、写真付きのときは写真入りのKMZ(pins.kmz)になります。
・更新後はアプリを2回開き直すと新しい版になります。

【v36 写真をLINEで送る】
・LINEのリンクでは文章しか送れないため、写真は2回に分けて送ります。
  ①「LINEで送る」…位置(地図リンク)とコメントを文章で送信。
  ②「📷 写真をLINEへ」…共有メニューが開くのでLINEを選び、相手を選んで写真を送信。

【v37 ピンの位置の微調整/ボタン名変更】
・ピンを立てた直後(または編集画面)の「🎯 位置を微調整」で、ピンの位置を動かせます。
  ピンの先端(◎)をドラッグ(拡大鏡が出ます)、または ◀▲▼▶ で少しずつ移動 → 「決定」。「元に戻す」で調整前の位置に戻ります。
・「LINEで送る」を「位置をLINEで送る」(一覧は「全部をLINEで送る」)に変更しました。

【v38 点マーカーを○で表示】
・SXFの点マーカー(point_marker_feature)がすべて「＋」(十字)で描かれていたのを、マーカー種別に合わせて描くよう修正しました。
  種別3など=○、4=●、5=×、2=＋、1=・。(SIMの点は従来どおり＋)

【v39 SXFのシンボル(プロットマーク等)を正しく描画】
・SXFの「シンボル」(sfig_org / sfig_locate)を展開して、配置位置・大きさ・向きどおりに描くようにしました。
  これまでは配置位置に「＋」(トンボ)だけを置いていたため、○(二重丸など)のプロットマークが十字で表示されていました。
・図面全体を縮小して紙面に置く「座標系」シンボルは、実座標のまま描きます。

【v40 ◎の内側を点で表示】
・プロットマーク(◎)の中心を、小さな○ではなく塗りつぶしの点(・)で表示します(マーカー種別3)。

【v41 補助線(線種0・線幅0)を表示しない】
・SXFで「線種0・線幅0」の図形(面の範囲指定などに使われる非表示の補助線)は描かないようにしました。
  図中に大きな正方形が出ていたのはこれが原因です。

【v42 線種(破線・点線・鎖線)の表示】
・SXFの線種に対応しました。1=実線、2=破線、3=隠れ線、4〜6=長破線+点、7=点線、8・9=鎖線、10〜15=破線+点の組合せ。
・ファイル内で定義された線種(ユーザー定義、17番〜)も、定義どおりの長さで描きます。
・点や破線の間隔は画面上の長さで固定しています(拡大縮小しても見た目は同じ)。

【v43 座標系の自動判定を厳しくしました】
・GeoTIFF/KML/現在地から座標系を推定するとき、基準位置から80km以内に収まる系だけを採用します(以前は300km)。
  現在地が現場から遠いと、別の県の系が選ばれて背景が別の場所に出ていました。
・X/Y入替・別単位で当てはめる場合は20km以内のときだけ採用します。
・該当する系がないときは、図面内の県名→前回の系→(なければ)「座標系を選んでください」の順で判定します。

【v44 読み込みの進み具合(%)をすべてのファイルで表示】
・SFC・SIM・GeoTIFFの読み込み、背景地図のオフライン保存でも、進行バーと「◯◯ n%」を表示します(KML/KMZは従来どおり)。
・大きいファイルは「取り込み中 → 解析中 → 描画データを作成中」の順に進みます。小さいファイルは一瞬で終わるため表示しません。

【v45 ピンの見た目を変更】
・ピンを「上に色付きの○、その中心から真下に伸びる針」の形に変えました。針の先が立てた位置です。

【v46 縦書き文字を縦に表示】
・SXFの文字で「縦書き」指定のものは、1文字ずつ上から下へ並べて表示します(基準点・回転角・文字間隔にも対応)。

【v47 縦書き文字の大きさ】
・縦書きの文字は、SXFでは「高さ=文字列全体の長さ、幅=1文字の大きさ」と指定されているため、1文字の大きさを「幅」の値にしました(以前は大きすぎました)。

【v48 大きなSFC図面の描画】
・図形が約3万本ある大きなSFC図面で、線がまとめて描かれず点だけが表示されることがあったため、線を4000本ずつに分けて描画するようにしました。

【v49 KMLの文字の隣の丸印】
・KMLの点で、アイコンの大きさが0(文字だけの点)に指定されているものは、丸印を描かず文字だけを表示します。文字の色と大きさもKMLの指定(LabelStyle)に従います。

【v50 KMLの文字サイズ】
・KMLの文字が小さすぎたため、画面上で最低14pxの大きさで表示するようにしました(KMLで大きい指定の文字は最大2倍)。

【v51 KMLの文字サイズ微調整】
・KMLの文字を最低17pxに、ほんの少し大きくしました。

【v52 アプリ名】
・アプリの名前を「今どこ君」にしました(ホーム画面・インストール時の表示)。

【v53 名称の統一】
・アプリ内の案内文・説明書の名称を「今どこ君」に統一しました。
